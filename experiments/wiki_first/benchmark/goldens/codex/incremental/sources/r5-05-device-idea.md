# Побочная идея из чата

СИНТЕТИЧЕСКИЙ МАТЕРИАЛ. Идея не относится к реальному устройству.

Алексей предложил хранить переводы интерфейса терминала не в прошивке, а в сменном языковом пакете.
Это могло бы позволить исправлять текст без полного обновления устройства.

Никто не проверял объём памяти, подпись пакетов или совместимость версий. Решения о разработке нет;
идею записали для отдельного исследования, потому что она не связана напрямую с процессом заказа.
