## Текущий продукт

После запуска:

```bash
uv run memorex app ./my-knowledge
```

пользователь может без AI создать, вручную изменить и найти Note, разложить Notes по Notebooks,
добавить вложения, открыть History и перенести весь workspace архивом. Экран «Добавить» создаёт
Packet для фонового AI-разбора. Экран «Обсуждения» запускает постоянный разговор по явно выбранным
Notes и позволяет сохранить ответ как новую Note.

Ручная правка применяется сразу. AI proposal требует Review. Ожидание Review не блокирует очередь.
Оборванный Discussion turn сохраняет вопрос и допускает retry.

## Ближайшая работа

Не начинать с большой перестройки. Сначала дать текущему интерфейсу пожить на реальных данных.
Исправлять только конкретные неудобства Capture, библиотеки Notes, редактора, поиска и Discussion.

После этого отдельным обсуждением спроектировать минимальные Commitments:

- ручное действие, связанное с Note/Packet;
- несколько понятных состояний;
- необязательный due/deadline;
- простой Today;
- подтверждение неуверенного AI extraction.

Attention, внешние уведомления, Telegram, VPS и mobile идут позже.

## Технические ориентиры

- не ломать существующие snapshots и migrations;
- обычные Note operations не должны зависеть от model runner;
- sources/originals immutable, derived indexes rebuildable;
- Discussion использует только видимый контекст;
- любой новый model output валидируется;
- offline tests используют fake runner;
- при изменении поведения обновлять README и implementation status.

## Границы

- приложение локальное, loopback-only и однопользовательское;
- backup/restore выполняет полную замену, не merge;
- URL пока только сохраняются;
- отдельного PDF/OCR pipeline нет;
- Commitments/Today/Attention ещё не реализованы;
- OpenCode/Hermes-hosted исследования принадлежат отдельной экспериментальной ветке, а не ядру
  продукта.
