## Overview

Личная локальная внешняя память на Markdown: надёжный заметочник в духе Evernote с опциональным AI-разбором поверх. Пользовательская правка это решение и применяется сразу, правка ИИ это предложение и требует Review. Работает полностью без AI и без сети: обычные заметки, блокноты, локальный полнотекстовый поиск, вложения, история версий, перенос всего workspace архивом. Прямое воплощение интереса [[me|к сложным неаккуратным материалам]]: код, чаты, голосовые расшифровки, документы, личные архивы.
