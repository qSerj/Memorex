## Пять вопросов

1. Где в системе используется ИИ.
2. Где хватит дешёвого или локального, если такой вариант есть.
3. Как работать совсем без ИИ: достать накопленное и сохранить идею или текст без редактуры,
   хотя бы первичное сохранение.
4. Рабочие процессы обсуждения и раскручивания идей.
5. Чем это сильнее разрозненных веб-чатов.

## Заготовка ответа на вопросы 1 и 3

Разложено по фактически существующим операциям [[MemorexClaude]], а не по замыслу.

| Операция | Чем закрывается |
|---|---|
| Сохранить оригинал в `sources/` | без модели, перемещение файла |
| Быстрый захват мысли | без модели, строка в `inbox/` |
| Чтение и навигация | без модели: [[Obsidian]], обратные ссылки, несвязанные упоминания |
| Поиск по словам | без модели: `grep`, поиск Obsidian |
| История, диффы, откат | без модели: `git` |
| Правка страницы руками | без модели, и правилами это разрешено как решение |
| Поиск по смыслу | дешёвая локальная: эмбеддинги, генерация не нужна |
| Подсказка тегов, маршрутизация `remember`/`ingest` | дешёвая |
| Пересказ одного короткого источника | дешёвая |
| Разбор большого грязного входа на темы | сильная |
| Противоречия между источниками и между страницами | сильная |
| Решение, куда встроить и что переписать | сильная |
| Синтез по многим страницам, обсуждение | сильная |
| «Что стоит выяснить дальше» | сильная |

Первичное сохранение и чтение не требуют модели вообще. Это уже так, а не пожелание.

## Заготовка ответа на вопрос 2

Ключевое наблюдение: **ворота `ingest` снижают требование к качеству модели.** Без ворот нужна
модель, которой доверяешь без надзора. С воротами достаточно модели, дающей полезный черновик,
потому что его всё равно читает и правит человек. Механизм, позволяющий удешевить ИИ, в
архитектуре уже стоит и поставлен по другой причине.

Граница трезвая: на девяти черновиках слабая модель создаст больше работы, чем сэкономит.
Дешёвая годится там, где выполняются оба условия сразу: человек и так собирался проверять, и
вывод короткий и структурный. Для синтеза не годится.

Отдельно проверяется гипотеза заменяемости сильной модели: `AGENTS.md` положен в хранилище
2026-09-02, прогон под Codex ещё не сделан.

## Найденная дыра: вопрос 4 нигде не описан

Скиллы закрывают захват (`remember`, `ingest`) и обслуживание (`review`). Самой ценной операции,
ради которой всё и затевалось, нет ни скилла, ни описания процесса. Словами [[qSerj]] это
«память, над которой я могу совместно с ИИ работать: обсуждать, придумывать, что-то формулировать,
переиначивать, обмозговывать».

Сейчас это держится на том, что человек и модель просто разговаривают, а правило «предлагать
сохранить» ловит результат постфактум. То есть самая ценная часть системы единственная, которая
никак не описана. Это и есть главный кандидат в работу по пункту 4, и вопрос 5 без него
не отвечается: сила против разрозненных чатов ровно в том, что разговор оставляет след.
