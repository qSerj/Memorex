# memory-kit

Установщик внешней памяти на markdown. Один скилл и набор шаблонов. Разворачивает хранилище в
любом каталоге, где его запустили, и умеет обновлять правила в уже развёрнутых.

## Что получается

```text
CLAUDE.md            правила, грузятся каждый ход
.claude/skills/      remember, ingest, review
sources/             оригиналы как пришли, только добавляются
memory/              страницы знаний, плоско, связи через [[wikilinks]]
actions/             open.md и done.md
inbox/               входящее и пины
log/friction.md      журнал трения
documents/           только если в хранилище производятся договоры и регламенты
```

Плюс `git init` и первый коммит.

## Установка комплекта

Один раз на машину:

```bash
ln -s ~/Projects/memory-kit ~/.claude/skills/memory-setup
```

Симлинк, а не копия: правку правил здесь подхватят все будущие хранилища.

## Как завести хранилище

```bash
mkdir ~/Projects/НовоеХранилище && cd ~/Projects/НовоеХранилище && claude
```

Дальше сказать «заведи память». Скилл задаст три вопроса и соберёт каркас. Больше ничего делать
не надо.

## Как обновить правила в существующем хранилище

Зайти в него и сказать «обнови правила памяти». Правила и скиллы заменятся на свежие, память,
источники, действия и журнал останутся нетронутыми. Шапка `CLAUDE.md`, где описано назначение
конкретного хранилища, тоже сохранится.

## Порядок работы с правилами

Комплект это единственный источник правил. Правку делать здесь, потом раскатывать по хранилищам.
Правка, сделанная внутри хранилища и не перенесённая сюда, потеряется при следующем обновлении.

## Откуда это

Правила выращены в `~/Projects/MemorexClaude` на реальном использовании: разбор расшифровок
разговоров, статей и заметок. Каждое правило здесь либо решает записанную в журнал боль, либо
взято из чужого опыта эксплуатации такого же хранилища.
