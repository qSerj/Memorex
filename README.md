# LLM Knowledge Lab — Starter Pack

Пакет предназначен для старта проекта в Codex/другом coding-agent CLI.

Рекомендуемый порядок чтения:

1. `00_PROJECT_CONTEXT.md` — зачем проект нужен и основные принципы.
2. `01_ARCHITECTURE_IDEAS.md` — карта архитектурных идей и соседних подходов.
3. `02_MVP_AND_EVOLUTION.md` — как начать с малого и развивать систему.
4. `03_CODEX_STARTER_BRIEF.md` — краткий brief непосредственно для coding agent.
5. `04_OPEN_QUESTIONS.md` — темы, которые лучше обсуждать отдельно, а не зашивать в код сразу.

Главная идея:
**не строить еще один RAG или Obsidian-плагин; строить локальный knowledge compiler, где источники неизменяемы, provenance проверяем, synthesis отделен от evidence, а retrieval можно постепенно усложнять.**
